# Assembly8086 Learning

8086 汇编语言课程作业与个人学习记录。

## 开发环境

- DOSBox 0.74-3
- MASM 5.00
- LINK 3.60
- DEBUG
- Visual Studio 2022

## 目录说明

### 根目录

- `HELLO.ASM`：第一个汇编程序

### HW02：ASCII 输出

- `LOOP.ASM`：使用循环输出 ASCII 小写字母
- `JUMP.ASM`：使用条件跳转输出 ASCII 小写字母
- `ASCII.c`：C 语言实现及反汇编实验

### HW03：求和与进制转换

- `HEX2DEC.ASM`：十六进制转十进制
- `DEC2HEX.ASM`：十进制转十六进制
- `SUM.ASM`：计算 1+2+...+100
- `SUMSTOR.ASM`：求和结果在寄存器、数据段和栈中的保存实验
- `SUMIN.ASM`：输入 N 并计算 1+2+...+N
- `SUM.c`：C 语言求和及反汇编实验

## 说明

本仓库主要保存源码和学习文档。编译生成的 `.EXE`、`.OBJ` 等文件不纳入版本管理。
